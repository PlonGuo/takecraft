## 验证与审阅

提交前基线：`pnpm typecheck`、`pnpm build` 与 19 个文件中的 67 项测试通过；Skill 校验通过。此前独立审阅的祖先裁剪、非法父对象、恢复锁再次中断三个问题均已修复并有回归。

本次提交前检查另发现两类边界，已定向修复：

- 动画 SVG 会自行播放，破坏同一 seek 时间的截图一致性。现在统一把图片准备为单帧 PNG；动态图取首帧，SVG 栅格化。预览和渲染使用相同字节，规范化图片哈希也进入视觉缓存。
- 轴对齐包围盒无法准确检查旋转和圆角容器的裁剪。现在将对象四角变换到裁剪祖先的本地坐标，再检查边界与圆角。

新增回归先出现 3 个预期失败，修复后定向测试通过。最终 `pnpm typecheck`、`pnpm build` 与 `pnpm test` 全部通过：19 个文件、73/73（52 单元、13 浏览器、8 端到端），全套耗时 86.10 秒。包含重新生成两版 15 秒视频和完整解码；不以通过构建代替行为验证。

迁移到稳定主目录后，安装、类型检查、构建与 doctor 均通过；完整测试同时扫描了主目录和旧 worktree，两份共 38 文件、146 项全部通过（164.89 秒）。随后将测试发现范围限定为当前目录的 `tests/**/*.test.ts`，核实只发现上述 19 个测试文件，避免嵌套 worktree 重复执行。

计划细项仍有四项专门测试未补全：surface 跨三节拍身份、字体加载失败时 ready 拒绝、渲染时 seek 异常注入、反向字幕区间。相关实现逻辑已有；没有声称这些特定验证均已执行。当前样片已被用户观看并总体认可，Agent 没有独立完成实时听感或主观音画同步验收。
