# Takecraft

通过 Skill 使用的本地视频制作工具链：Agent 负责创意和制作清单，固定程序负责动画、渲染、声音、编码与技术检查。

目标是让常见产品动效片复用组件和生产流程，减少每次从零生成代码所需的 token，同时保留定制效果的扩展入口。

## 当前状态

仓库已初始化，架构和 M1 实施计划已写入版本控制。**产品代码、CLI、渲染器和 Skill 尚未实现**；计划文档中的命令是目标接口，现在不能直接运行。

## 第一阶段目标

输入产品截图、名称、卖点和制作清单，输出 15 秒、1080p30 的产品动效 MP4、预览图和检查报告。支持基础合成音效、用户提供的音乐/旁白、定时字幕，以及按阶段缓存和失败恢复。

自动配音、逐词对齐、运动模糊、4K60 和三维能力在后续阶段实现。

## 实现原则

- 制作清单是唯一人工编辑的制作事实来源，生成文件不单独维护。
- 复用持续存在的对象、动作和镜头，保持跨段衔接。
- 确定性生产流程不调用语言模型；Agent 只参与创作和必要的修改。
- 技术检查和审美评价分开，不能用编译通过代替成片验收。
- 独立实现代码与示例，不复制 onetake 的受限代码、模板或素材。

拟采用 Node.js 22、TypeScript、pnpm、Playwright 和 FFmpeg。依赖安装、版本锁定及运行命令在实施计划的第一项任务完成后补入本 README。
